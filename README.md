## Run it

Open `index.html` in your browser.

If you change the Tailwind classes, rebuild the CSS with the Tailwind standalone CLI:

```bash
./tailwindcss -i css/input.css -o css/tailwind.css --minify
```

(`tailwindcss-windows-x64.exe` in this folder is the Windows version of that CLI.)
